# Universal Media Downloader Bot

Telegram бот для скачивания видео и музыки

## Возможности
- 📸 Instagram (публичные посты, Reels)
- ▶️ YouTube (все видео, Shorts)
- 🎵 TikTok (видео без водяного знака)
- 🎶 Музыка (поиск по названию, SoundCloud, Spotify)
